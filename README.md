# Shared character state

This branch holds nothing but `state.json`, the live state of the two character
sheets on the `main` branch: hit points, resource pips, kit, coin, ability
scores, level and session notes.

The page writes here every time an edit is saved, so it lives on its own branch
for two reasons: `main`'s history stays readable, and GitHub Pages does not
rebuild the site once per hit point.

Do not edit this file by hand while the page is open — the next save will
overwrite it. To roll back, check out an older revision of `state.json`, then
open the page and use **Backup → Show data → Apply pasted data**.
